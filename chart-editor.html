① 음악 불러오기

아직 파일을 안 골랐어요. (파일은 어디에도 올라가지 않고 이 화면에서만 재생돼요)

② 자동으로 채보 만들기 — 이것만 누르면 돼요

음악을 직접 들어보고 박자를 찾아서 채보를 만들어요. 손으로 찍을 필요 없어요.
⚙️ 세부 설정 · 직접 찍기 — 자동으로 만들면 안 눌러도 돼요

③ 건반음 — 누를 때 나는 소리

레인마다 다른 음이 나요. 5음계는 어떤 곡에 얹어도 어울려서 무난해요.

④ 박자 정리 (자동 생성이 알아서 해줘요)

손으로 친 타이밍을 격자에 딱 맞춰 줍니다. BPM을 모르면

⑤ 미리듣기 · 직접 찍기

시간 0.0 / 0.0초 노트 0개 롱노트 0개
키보드 D F J K · 길게 누르면 롱노트 · 스페이스 재생/정지 · Ctrl+Z 되돌리기
녹음을 다시 시작해도 이미 찍은 노트는 남아요. 특정 구간만 다시 찍고 싶으면 타임라인을 눌러 그 지점으로 옮긴 뒤 녹음하세요.

⑥ 다시 다듬기 — 박자는 그대로, 배치만 새로

아무 손가락으로 박자만 찍어두면, 여기서 레인 배치를 손맛 좋게 다시 짜 드려요. 빠른 구간은 계단으로, 강박은 동시치기로, 긴 여백은 롱노트로 바꿔요. 박자(치는 시점)는 절대 안 건드려요.

✏️ 노트 직접 고치기

멈춘 상태에서 격자를 눌러 노트를 넣고 뺄 수 있어요. 다시 누르면 지워지고, 노트를 길게 누르면 롱노트가 됩니다. 타임라인을 눌러 원하는 구간으로 이동하세요.
